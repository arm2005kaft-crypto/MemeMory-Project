# MemeMory

A dedicated web-based platform for university students to share, organize, and discover course-related educational memes to make exam revision more engaging and efficient.

## Project Overview
University students often struggle to recall complex academic concepts while wasting time searching through scattered, unorganized content across social media and group chats. MemeMory provides a centralized, academically-focused environment where students can upload, search, favorite, and report course-related memes without distractions.

## Key Features
- **User Authentication:** Secure registration, login, and logout functionality using university emails.
- **Meme Management:** Upload educational memes with titles, optional short descriptions, and course tags. Users can also view, edit, and delete their own posts.
- **Course Search & Filtering:** Quickly find relevant academic memes categorized by course subjects.
- **Personal Favorites:** Bookmark useful memes for quick re-access during exam revisions.
- **Content Reporting:** Report posts that are unrelated to academic subjects to maintain a clean educational environment.

## System Architecture & Tech Stack
- **Architecture:** Three-tier client-server architecture (Presentation Layer, Application/Business Logic Layer, Data Layer).
- **Database & Storage:** Firebase Firestore (Document-oriented NoSQL database) using a referencing approach to manage STUDENT, MEME_POST, and REPORT collections efficiently.
- **Frontend / Backend:** Web-based responsive interface accessible across modern browsers (mobile, tablet, desktop).
